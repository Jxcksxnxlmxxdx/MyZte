# ZTE Config Assistant

Aplicativo Android para leitura de etiquetas de ONUs/roteadores, identificação de SSID e senha Wi-Fi e solicitação de conexão pelo Android.

## Primeira etapa
- Captura de imagem da etiqueta
- OCR para identificar SSID e senha
- Conferência dos dados encontrados
- Solicitação de conexão Wi-Fi com aprovação do Android

## Próximas etapas
- Descoberta do gateway local
- Interface de configuração do roteador

Projeto em desenvolvimento.
